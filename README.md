# 跨标签页共享计数器

一个无后端的单计数器，使用 `BroadcastChannel` 做标签页实时广播，用 IndexedDB 做持久化和恢复来源。

## 运行

```bash
npm test
python3 -m http.server 8080
```

然后打开 `http://localhost:8080`，复制出多个标签页操作。

## 一致性设计

- 每次加一、减一都是只追加的 `delta` 操作，重置是带因果时钟快照的 `reset` 操作。
- 重置只抵消它已经观察到的加减操作；未观察到的并发或离线加减不会被覆盖。
- 每个操作有全局唯一 ID，重复消息直接忽略，乱序消息可按因果关系重新计算出同一结果。
- 操作先写入 IndexedDB，再更新界面和广播，因此标签页关闭或刷新后可从本地恢复。
- 标签页每秒用 IndexedDB 做一次对账，也能在浏览器支持有限或广播错过时补齐操作。

## 验收场景

- 4 个标签页各加 100 次：所有 `delta` 都会保留，结果为 400。
- 4 个标签页同时重置：重置操作幂等去重后，结果为 0。
- 操作后关闭标签页：操作已经在 IndexedDB，新标签页启动会读取。
- 离线加减后恢复：离线操作保留在本地 IndexedDB，恢复后通过共享存储和广播汇合。
- 消息乱序或重复：归并结果不依赖到达顺序，重复 ID 不重复计数。
- 刷新任意标签页：启动时重放 IndexedDB 中的操作日志。
